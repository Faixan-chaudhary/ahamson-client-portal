# Windows RDP Deployment Guide

Deploy the AHamson Client Document Portal on a Windows Server / RDP machine.

## Architecture (single server)

```
Browser → http://SERVER_IP:8080
              ├── /admin/*     → React frontend (dist/)
              ├── /client/*    → React frontend (dist/)
              └── /api/*       → FastAPI backend + SQLite
```

One process serves both frontend and API — no separate nginx/IIS required.

---

## Prerequisites (install on Windows RDP)

1. **Python 3.11+** — https://www.python.org/downloads/  
   Check "Add Python to PATH" during install.

2. **Node.js 20 LTS** — https://nodejs.org/

3. Copy the full project folder to the server, e.g.  
   `C:\Apps\Corporate-SaaS-UI-Design\`

---

## Quick deploy (3 commands)

Open **PowerShell** in the project folder:

```powershell
Set-ExecutionPolicy -Scope Process Bypass

# Replace 192.168.1.50 with your RDP server IP
.\deploy\windows\setup.ps1 -ServerIp "192.168.1.50"

# Edit password before going live
notepad backend\.env

# Start the app
.\deploy\windows\start.ps1
```

Open browser: **http://192.168.1.50:8080/admin/login**

## Manual configuration

### `backend\.env` (important fields)

| Variable | Example | Notes |
|----------|---------|-------|
| `ENVIRONMENT` | `production` | Required |
| `SECRET_KEY` | 48-char random | Auto-generated by setup.ps1 |
| `ADMIN_PASSWORD` | strong password | **Change this!** |
| `CORS_ORIGINS` | `http://192.168.1.50:8080` | Your server URL |
| `FRONTEND_URL` | `http://192.168.1.50:8080` | Used in emails |
| `SERVE_FRONTEND` | `true` | Serves React build |
| `PORT` | `8080` | App port |
| `SMTP_*` | your mail server | For link/reset emails |

### `.env.production` (frontend build)

```env
VITE_API_URL=
VITE_APP_URL=http://192.168.1.50:8080
```

Leave `VITE_API_URL` empty — API calls go to the same server (`/api/...`).

## Firewall

Setup script opens port 8080 automatically. To open manually:

```powershell
New-NetFirewallRule -DisplayName "AHamson Portal" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8080
```

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `ModuleNotFoundError: openpyxl` (or crash on `uvicorn app.main:app`) | Reinstall deps: `cd backend` then `.\venv\Scripts\pip.exe install -r requirements.txt` |
| Port already in use | Change `PORT` in `backend\.env` |
| Blank page | Run `npm run build` again |
| API 401 / CORS error | Match `CORS_ORIGINS` and `VITE_APP_URL` to exact browser URL |
| Can't access from other PCs | Check Windows Firewall + server IP |
| Database | SQLite file at `backend\ahamson.db` — back this up regularly |

### Full error text (important)

If uvicorn crashes on start, scroll to the **last line** of the traceback (e.g. `ModuleNotFoundError: No module named 'openpyxl'`). That last line is the real cause — the middle of the stack is usually just uvicorn importing `app.main`.

```powershell
cd "C:\websites\AHamson Client Portal\backend"
.\venv\Scripts\pip.exe install -r requirements.txt
.\venv\Scripts\uvicorn.exe app.main:app --host 0.0.0.0 --port 8080
```

After any code update that touches `requirements.txt`, always re-run pip install before starting uvicorn.

## Security checklist (production)

- [ ] Change `ADMIN_PASSWORD` from default
- [ ] Set strong `SECRET_KEY` (32+ chars)
- [ ] Configure SMTP for email notifications
- [ ] Restrict RDP access to trusted users
- [ ] Back up `backend\ahamson.db` daily
- [ ] Use HTTPS via reverse proxy (IIS/nginx) if exposed to internet
